**1. Place Value, Rounding, and Algorithms for Addition and Subtraction**

- _A. Place Value of Multi-Digit Whole Numbers_
  - 1. Interpret a multiplication equation as a comparison.
  - 2. Recognize a digit represents 10 times the value of what it represents in the place to its right.
  - 3. Name numbers within 1 million by building understanding of the place value chart and placement of commas for naming base thousand units.
  - 4. Read and write multi-digit numbers using base ten numerals, number names, and expanded form.
- _B. Comparing Multi-Digit Whole Numbers_
  - 5. Compare numbers based on meanings of the digits using >, <, or = to record the comparison.
  - 6. Find 1, 10, and 100 thousand more and less than a given number.
- _C. Rounding Multi-Digit Whole Numbers_
  - 7. Round multi-digit numbers to the thousands place using the vertical number line.
  - 8. Round multi-digit numbers to any place using the vertical number line.
  - 9. Use place value understanding to round multi-digit numbers to any place value.
  - 10. Use place value understanding to round multi-digit numbers to any place value using real world applications.
- _D. Multi-Digit Whole Number Addition_
  - 11. Use place value understanding to fluently add multi-digit whole numbers using the standard addition algorithm, and apply the algorithm to solve word problems using tape diagrams.
  - 12. Solve multi-step word problems using the standard addition algorithm modeled with tape diagrams, and assess the reasonableness of answers using rounding.
- _E. Multi-Digit Whole Number Subtraction_
  - 13. Use place value understanding to decompose to smaller units once using the standard subtraction algorithm, and apply the algorithm to solve word problems using tape diagrams.
  - 14. Use place value understanding to decompose to smaller units up to three times using the standard subtraction algorithm, and apply the algorithm to solve word problems using tape diagrams.
  - 15. Use place value understanding to fluently decompose to smaller units multiple times in any place using the standard subtraction algorithm, and apply the algorithm to solve word problems using tape diagrams.
  - 16. Solve two-step word problems using the standard subtraction algorithm fluently modeled with tape diagrams, and assess the reasonableness of answers using rounding.
- _F. Addition and Subtraction Word Problems_
  - 17. Solve additive compare word problems modeled with tape diagrams.
  - 18. Solve multi-step word problems modeled with tape diagrams, and assess the reasonableness of answers using rounding.
  - 19. Create and solve multi-step word problems from given tape diagrams and equations.

**2. Unit Conversions and Problem Solving with Metric Measurement**

- _A. Metric Unit Conversions_
  - 1. Express metric length measurements in terms of a smaller unit; model and solve addition and subtraction word problems involving metric length.
  - 2. Express metric mass measurements in terms of a smaller unit; model and solve addition and subtraction word problems involving metric mass.
  - 3. Express metric capacity measurements in terms of a smaller unit; model and solve addition and subtraction word problems involving metric capacity.
- _B. Application of Metric Unit Conversions_
  - 4. Know and relate metric units to place value units in order to express measurements in different units.
  - 5. Use addition and subtraction to solve multi-step word problems involving length, mass, and capacity.

**3. Multi-Digit Multiplication and Division**

- _A. Multiplicative Comparison Word Problems_
  - 1. Investigate and use the formulas for area and perimeter of rectangles.
  - 2. Solve multiplicative comparison word problems by applying the area and perimeter formulas.
  - 3. Demonstrate understanding of area and perimeter formulas by solving multi-step real world problems.
- _B. Multiplication by 10, 100, and 1,000_
  - 4. Interpret and represent patterns when multiplying by 10, 100, and 1,000 in arrays and numerically.
  - 5. Multiply multiples of 10, 100, and 1,000 by single digits, recognizing patterns.
  - 6. Multiply two-digit multiples of 10 by two-digit multiples of 10 with the area model.
- _C. Multiplication of up to Four Digits by Single-Digit Numbers_
  - 7. Use place value disks to represent two-digit by one-digit multiplication.
  - 8. Extend the use of place value disks to represent three- and four-digit by one-digit multiplication.
  - 9–10. Multiply three- and four-digit numbers by one-digit numbers applying the standard algorithm.
  - 11. Connect the area model and the partial products method to the standard algorithm.
- _D. Multiplication Word Problems_
  - 12. Solve two-step word problems, including multiplicative comparison.
  - 13. Use multiplication, addition, or subtraction to solve multi-step word problems.
- _E. Division of Tens and Ones with Successive Remainders_
  - 14. Solve division word problems with remainders.
  - 15. Understand and solve division problems with a remainder using the array and area models.
  - 16. Understand and solve two-digit dividend division problems with a remainder in the ones place by using place value disks.
  - 17. Represent and solve division problems requiring decomposing a remainder in the tens.
  - 18. Find whole number quotients and remainders.
  - 19. Explain remainders by using place value understanding and models.
  - 20. Solve division problems without remainders using the area model.
  - 21. Solve division problems with remainders using the area model.
- _F. Reasoning with Divisibility_
  - 22. Find factor pairs for numbers to 100, and use understanding of factors to define prime and composite.
  - 23. Use division and the associative property to test for factors and observe patterns.
  - 24. Determine if a whole number is a multiple of another number.
  - 25. Explore properties of prime and composite numbers to 100 by using multiples.
- _G. Division of Thousands, Hundreds, Tens, and Ones_
  - 26. Divide multiples of 10, 100, and 1,000 by single-digit numbers.
  - 27. Represent and solve division problems with up to a three-digit dividend numerically and with place value disks requiring decomposing a remainder in the hundreds place.
  - 28. Represent and solve three-digit dividend division with divisors of 2, 3, 4, and 5 numerically.
  - 29. Represent numerically four-digit dividend division with divisors of 2, 3, 4, and 5, decomposing a remainder up to three times.
  - 30. Solve division problems with a zero in the dividend or with a zero in the quotient.
  - 31. Interpret division word problems as either number of groups unknown or group size unknown.
  - 32. Interpret and find whole number quotients and remainders to solve one-step division word problems with larger divisors of 6, 7, 8, and 9.
  - 33. Explain the connection of the area model of division to the long division algorithm for three- and four-digit dividends
- _H. Multiplication of Two-Digit by Two-Digit Numbers_
  - 34. Multiply two-digit multiples of 10 by two-digit numbers using a place value chart.
  - 35. Multiply two-digit multiples of 10 by two-digit numbers using the area model.
  - 36. Multiply two-digit by two-digit numbers using four partial products.
  - 37–38. Transition from four partial products to the standard algorithm for two-digit by two-digit multiplication.

**4. Angle Measure and Plane Figures**

- _A. Lines and Angles_
  - 1. Identify and draw points, lines, line segments, rays, and angles. Recognize them in various contexts and familiar figures.
  - 2. Use right angles to determine whether angles are equal to, greater than, or less than right angles. Draw right, obtuse, and acute angles.
  - 3. Identify, define, and draw perpendicular lines.
  - 4. Identify, define, and draw parallel lines.
- _B. Angle Measurement_
  - 5. Use a circular protractor to understand a 1-degree angle as 1360 of a turn. Explore benchmark angles using the protractor.
  - 6. Use varied protractors to distinguish angle measure from length measurement.
  - 7. Measure and draw angles. Sketch given angle measures, and verify with a protractor.
  - 8. Identify and measure angles as turns and recognize them in various contexts.
- _C. Problem Solving with the Addition of Angle Measures_
  - 9. Decompose angles using pattern blocks.
  - 10–11. Use the addition of adjacent angle measures to solve problems using a symbol for the unknown angle measure.
- _D. Two-Dimensional Figures and Symmetry_
  - 12. Recognize lines of symmetry for given two-dimensional figures. Identify line-symmetric figures, and draw lines of symmetry.
  - 13. Analyze and classify triangles based on side length, angle measure, or both.
  - 14. Define and construct triangles from given criteria. Explore symmetry in triangles.
  - 15. Classify quadrilaterals based on parallel and perpendicular lines and the presence or absence of angles of a specified size.
  - 16. Reason about attributes to construct quadrilaterals on square or triangular grid paper.

**5. Fraction Equivalence, Ordering, and Operations**

- _A. Decomposition and Fraction Equivalence_
  - 1–2. Decompose fractions as a sum of unit fractions using tape diagrams.
  - 3. Decompose non-unit fractions and represent them as a whole number times a unit fraction using tape diagrams.
  - 4. Decompose fractions into sums of smaller unit fractions using tape diagrams.
  - 5. Decompose unit fractions using area models to show equivalence.
  - 6. Decompose fractions using area models to show equivalence.

  - 9–10. Use the area model and division to show the equivalence of two fractions.
  - 11. Explain fraction equivalence using a tape diagram and the number line, and relate that to the use of multiplication and division.
- _C. Fraction Comparison_
  - 12–13. Reason using benchmarks to compare two fractions on the number line.
  - 14–15. Find common units or number of units to compare two fractions.
- _D. Fraction Addition and Subtraction_
  - 16. Use visual models to add and subtract two fractions with the same units.
  - 17. Use visual models to add and subtract two fractions with the same units, including subtracting from one whole.
  - 18. Add and subtract more than two fractions.
  - 19. Solve word problems involving addition and subtraction of fractions.
  - 20–21. Use visual models to add two fractions with related units using the denominators 2, 3, 4, 5, 6, 8, 10, and 12.
- _E. Extending Fraction Equivalence to Fractions Greater Than 1_
  - 22. Add a fraction less than 1 to, or subtract a fraction less than 1 from, a whole number using decomposition and visual models.
  - 23. Add and multiply unit fractions to build fractions greater than 1 using visual models.
  - 24–25. Decompose and compose fractions greater than 1 to express them in various forms.
  - 26. Compare fractions greater than 1 by reasoning using benchmark fractions.
  - 27. Compare fractions greater than 1 by creating common numerators or denominators.
  - 28. Solve word problems with line plots.
- _F. Addition and Subtraction of Fractions by Decomposition_
  - 29. Estimate sums and differences using benchmark numbers.
  - 30. Add a mixed number and a fraction.
  - 31. Add mixed numbers.
  - 32. Subtract a fraction from a mixed number.
  - 33. Subtract a mixed number from a mixed number.
  - 34. Subtract mixed numbers.
- _G. Repeated Addition of Fractions as Multiplication_
  - 35–36. Represent the multiplication of n times a/b as (n × a)/b using the associative property and visual models.
  - 37–38. Find the product of a whole number and a mixed number using the distributive property.
  - 39. Solve multiplicative comparison word problems involving fractions.
  - 40. Solve word problems involving the multiplication of a whole number and a fraction including those involving line plots.
- _H. Exploring a Fraction Pattern_
  - 41. Find and use a pattern to calculate the sum of all fractional parts between 0 and 1. Share and critique peer strategies.
